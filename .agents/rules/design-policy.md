# 디자인 정책

이 파일은 지켜야 할 경계만 담는다. 토큰과 컴포넌트는 `docs/art/design-system.md`, 환경 표현과 화면 판정 규칙은 `docs/art/immersion-policy.md`, 글꼴은 `docs/art/typography.md`에 있다. `docs/art/style-guide.md`는 옛 기준이라 참고만 한다. 결정의 날짜와 이유는 `docs/memory/decisions.md`에 있다.

2026-11-08 현행화. 2~2.5등신, 파스텔 환경, 구운 그림자, 본문 28px 같은 옛 기준은 지웠다.

## 고정 사항

- 화면은 가로 우선이다. 16:9를 구성 기준으로 삼고 844×390, 740×360처럼 긴 가로 화면부터 1280×720까지 지원한다. 실제 뷰포트에 맞춰 렌더러·카메라·UI를 리사이즈하며 CSS로 화면을 회전하지 않는다. 세로 모바일에는 회전 안내 오버레이를 표시하고 위치·대화·선택 상태를 유지하며 이동 입력을 해제한다. 검증 해상도는 844×390, 740×360, 960×540, 1280×720이다.
- 쿼터뷰(3/4 탑다운) 시점. Three.js 3D 월드를 정사영 카메라로 표시한다. 줌·회전 조작은 두지 않는다.
- 캐릭터는 약 3등신. 공략 캐릭터 4명은 성별 중립이고 머리 실루엣과 대표색으로 구별한다. 주인공은 얼굴 없는 흰 알 껍질로, 명암과 껍질 경계는 보이되 피부색·성별 단서와 커스터마이징은 없다.
- 환경은 각진 저폴리다. 면이 보이는 플랫 셰이딩, 재료 색, 부재 단위 형태, 방향광 1개와 실시간 그림자를 쓴다. 인물은 환경보다 선명한 대표색을 가진다. 인물 셰이딩을 환경에 맞출지는 미결이다.
- 감정 표현은 머리 위 버블로 한다. 단, 측정 문항 반응에는 하트·물음표 버블을 쓰지 않는다(`game-design-policy.md`).
- 특정 게임의 이름, 캐릭터, 에셋, 외관을 복제하지 않는다.

## UI 규칙

- 이동 패드는 왼쪽 아래, 상호작용은 대상 탭과 오른쪽 아래 말하기 버튼. 대사창은 화면 하단, 선택지는 2~3개의 큰 알약 버튼.
- 터치 영역은 최소 48×48 CSS px.
- 본문 글자는 17px, 글자 크게 설정은 20px. 본문 텍스트 대비 4.5:1 이상. 글꼴은 Pretendard 조각 자체 호스팅.
- 대사는 탭으로 넘긴다. 자동 넘김 옵션은 예정(T025)이며, 넣을 때 끌 수 있어야 하고 측정 선택지에는 적용하지 않는다.
- 선택지 버튼은 모두 같은 모양·색·크기. 순서나 색으로 '정답'처럼 보이게 하지 않는다.
- 성향치·축 이름·호감도 숫자는 플레이 중 노출 금지. 호감도는 에피소드 끝 하트 5칸만.
- 진행도는 '기억 조각 n/12'. 조각은 구간 완료로만 얻고 선택 내용으로 차등을 두지 않는다(구현 예정, T023).
- UI는 기본 글자 크기의 정상 대화 화면에서 40%를 넘지 않는다.

## 에셋 규칙

- 3D 에셋은 GLB로 `client/public/assets/abraxas/` 아래에 두고 `content/assets/manifest.json`에 등록한다. 원본과 생성 스크립트는 `assets/source/`에 둔다.
- 2D 파일명은 `kebab-case`, 접두어로 종류 표시 (`bg-`, `chr-`, `ui-`, `fx-`, `card-`). 캐릭터·UI 에셋은 투명 배경 PNG, 배경은 WebP.
- 배포 묶음은 게임 10MB, 오프닝 영상 13MB를 넘지 않는다(`npm run check:size`). 영상은 첫 화면에서 받지 않는다.
- 생성형 AI로 만든 에셋은 `assets/_generated/`에 두고, 사람이 고른 것만 `client/public/assets/`로 옮긴다. 프롬프트는 같은 이름의 `.prompt.md`로 남긴다.
- 실존 캐릭터·브랜드·작품을 닮은 에셋은 쓰지 않는다.

## 측정 오염 금지 (아트·연출)

- 선택 전 NPC의 기대 답을 시선, 몸짓, 장소 색, 소리, 데미의 선행 방향으로 암시하지 않는다.
- 선택 직후에는 저장 확정 뒤 중립 반응 두 종류만 보여 준다. 평가색, 실패음, 되돌리기는 금지.
- 선택 후 주인공에 남기는 빛은 모든 답에 같은 방식만 쓴다. 성향과 색을 대응시키지 않는다.
