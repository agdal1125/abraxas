# T018-P3-b 조명

먼저 `docs/tasks/T018-P3-faceted-direction.md`를 읽는다. 셸 읽기는 자유롭다. 커밋·push 금지. **쓰기는 `client/src/scenes/`만.** 다른 작업자가 환경 애셋을 동시에 고친다.

`client/src/scenes/village.ts`의 조명을 또렷한 한 방향 빛으로 바꾼다. 감독이 게임에서 시험한 출발값은 반구광 0.75, 환경광 0.05, 방향광 2.9다. 그림자가 인물과 나무 아래에 분명히 보이도록 방향광의 방향과 그림자 설정(bias, 영역)을 확인한다. 새 광원·후처리는 넣지 않는다. 그림자 맵 상한을 올리지 않는다.

환경 애셋은 생성기에서 플랫으로 내보내므로 런타임 `flatShading`은 켜지 않는다. 인물 색이 어두워지거나 알 껍질 주인공이 탁해지면 안 된다. 인물 쪽 재질은 건드리지 않고 조명 값으로 균형을 맞춘다. 대비 때문에 대사창·UI가 달라지지 않는다. `dream-effects.ts`의 안개·발광이 인상을 뿌옇게 만들면 강도만 낮춘다.

`npm --prefix client run typecheck`, `npm --prefix client test`를 실행하고 한국어로 값과 근거, 검사 결과, 미확인 항목을 보고한다.
