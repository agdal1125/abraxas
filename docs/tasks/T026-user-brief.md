## 2026-11-10 main 화면에서 확인한 것 (740×360)

- 풀밭이 단색 평면이다. 풀 포기와 꽃은 놓여 있으나 작고 드물다. 인트로 영상의 풀잎 들판, 길가의 회색 바위, 울타리가 게임에는 보이지 않는다.
- 방향광이 카메라와 같은 쪽에서 들어온다(빛 위치 = 주인공 + (4, 10, 5), 카메라는 +x+z). 그림자가 물체 뒤로 숨어 건물과 나무의 그림자가 땅에 보이지 않는다.
- 움직이는 것은 꽃잎·반딧불 입자뿐이다. 나무, 풀, 물은 멈춰 있다.
- 보조 주민 네 명과 우체부가 같은 회색 모델이다.
