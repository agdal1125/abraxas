# T016 사람 요청 원문 — 시나리오를 실제 게임 대사로

2026-11-03 사람이 Claude에게 준 요청(/goal)을 고치지 않고 옮긴다. 모든 위임 에이전트는 이 원문을 기준으로 삼는다.

> 시나리오를 실제 게임 대사로 옮기는 작업을 진행해. 질문 없이 네가 생각하는 최적의 방향으로 진행하고, agy cli와 codex cli를 최대한 활용해. 첫 장면은 Cinematic 영상으로 표현할거야. 데미와 조우하고 난 이후부터 장면을 만들어줘. 영어 대사도 쓰고. 지금 시작해.

## 감독 해석

- '시나리오'는 main에 병합된 `docs/story/chapters/`(T015, PR #56)다.
- 첫 장면(Prelude: 하늘에서 알이 떨어지고, 하얀 주인공이 깨어나고, 데미가 다가와 핥는 데까지)은 사람이 별도로 시네마틱 영상으로 만든다. 게임은 그 영상이 들어갈 자리만 두고, 데미와 만난 직후(데미를 따라 마을로 걷는 장면)부터 실제 장면과 대사를 만든다.
- 질문 없이 진행한다. 판단이 필요한 곳은 측정 무결성 정책 안에서 감독이 결정하고 기록한다.
- 한국어와 영어 대사를 모두 쓴다.
