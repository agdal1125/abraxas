# T018-P2 4단계: 빵집 입면 보정

`docs/tasks/T018-P2-bakery-prototype.md`의 사람 결정과 금지 사항, `docs/tasks/T018-P2-step2-world.md`의 쓰기 범위는 그대로다. 셸 읽기는 자유롭다. 커밋·push 금지. `client/src`는 쓰지 않는다. 지금 결과에서 방향은 맞다. 감독이 게임 화면에서 본 다음 세 가지만 고친다.

1. **납작한 입면.** 두 빵집의 `rot`가 0.7854라 앞면이 카메라를 정면으로 향해 옆면이 전혀 안 보이고 입면도처럼 납작하다. 마을의 다른 집처럼 앞면과 옆면이 함께 보이게 `rot`를 고친다(앞면이 카메라에서 좌우로 비스듬한 값). 두 채의 값을 다르게 해 같은 모습으로 보이지 않게 해도 된다. 입구는 계속 보여야 한다. 충돌과 도달성을 다시 확인한다.
2. **문 앞을 막은 벤치.** 벤치가 `prop-9` 문 바로 앞에 있고 길이 문이 아니라 벤치로 이어진다. 벤치를 입구 옆으로 옮기고 벽과 평행하게 놓아, 길이 문까지 비어 있게 한다. 빵 상자 군집도 입구를 막지 않는지 본다. `prop-10`도 같은 기준으로 본다.
3. **차양 복원.** 이전 단계에서 줄무늬 차양까지 사라졌다. 창 위에 지지 구조가 있는 작은 줄무늬 차양을 다시 넣는다(벽에 고정된 앞단이 보이게). 앞서 없앤 큰 붉은 천은 되살리지 않는다. 지붕의 납작한 노란 덩어리가 빵 간판으로 안 읽히면 지지대가 있는 빵 모양 간판으로 고치거나 없앤다.

## 검사

`ABRAXAS_ENV_TARGETS=bakery`로 빵집만 빌드하고 프리뷰를 직접 본다. `node client/scripts/check-abraxas-assets.mjs`, `node scripts/check-village-reach.mjs`, `npm --prefix client test`를 실행한다. 빵집 예산 5,000삼각형·180KiB 안이어야 한다.

한국어로 새 rot, 옮긴 소품 ID, 삼각형·바이트, 검사 결과, 미확인 항목을 보고한다. 지형을 다시 빌드할 필요가 없으면 하지 않는다. 길을 입구로 잇는 데 꼭 필요할 때만 한다.
