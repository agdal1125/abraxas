# T018-F1 대사 글자 가독성

담당: agy 사용량 한도(429)로 Codex `gpt-6.1-terra`가 대체. 검수: Claude. 커밋·push 금지. 읽기 전용 셸 명령은 자유롭게 쓴다.

## 사람 요청 원문

> 화면과 같이 한국어 글씨가 깨져. 폰트가 해당 글자를 지원하지 않는 것 같아.
> 이 부분 수정해보자.

문제의 화면은 대사 "바구니 밑도 살펴뒀어. 어느 길로 갈래?"의 "뒀" 자리다.

## 감독이 측정한 사실

- 글꼴 범위 누락은 없다. 게임 한글 대사에 쓰인 글자는 모두 Pretendard 조각의 `unicode-range` 안에 있고 조각 파일 92개가 모두 있다. 대사 파일에 분해형 한글이나 특수 문자도 없다.
- 글꼴을 다 받은 뒤 "뒀"은 Pretendard로 그려진다. 시스템 글꼴과 픽셀이 다르다.
- 15px에서는 "뒀, 됐, 쌓, 놓"처럼 획이 많은 글자가 뭉개진다. 17px부터 또렷해진다. 원인 후보 하나다.
- 글꼴 조각을 글자가 필요할 때 받고 `font-display: swap`이므로, 처음 나오는 글자는 조각이 도착할 때까지 시스템 글꼴로 보일 수 있다. 원인 후보 둘이다.

## 할 일

1. **기본 글자 크기를 17px로 올린다.** `--body-size` 기본값을 15px에서 17px로, "글자 크게" 값을 18px에서 20px로 바꾼다(`client/src/ui/game.ts`, `client/src/style.css`). 이름표·보조 문구 같은 다른 크기는 비례가 깨질 때만 고친다.
2. **대사 글자를 미리 받는다.** 대사 JSON을 받는 곳(`client/src/ui/game.ts`의 `./ink/...` fetch 세 곳)에서 그 파일의 글자로 `document.fonts.load("400 17px 'Pretendard Variable'", 글자들)`을 호출하는 작은 함수 하나를 쓴다. 첫 대사를 띄우기 전에 최대 400ms까지만 기다리고, 실패하거나 시간이 넘어도 대사를 그대로 보여 준다. 글꼴 때문에 게임이 멈추면 안 된다. 제목 화면에서는 호출하지 않아 첫 화면 전송량을 늘리지 않는다.
3. **문서를 맞춘다.** `docs/art/design-system.md`의 `body` 줄과 'UI 크기' 줄, `docs/art/typography.md`의 해당 기준을 새 값과 이유로 고친다.
4. **크기 변경의 회귀를 고친다.** `scripts/e2e-play.mjs`의 글자 크기 검증값(15/18)을 새 값에 맞춘다. 740×360과 844×390에서 대사창, 선택지, 퍼즐 작업판이 넘치지 않아야 한다. 넘치면 스크롤되거나 줄바꿈되게 하되 CSS는 최소로 고친다. 대사창과 선택지가 화면의 40%를 넘지 않는 기존 원칙을 지킨다.

## 금지

대사 문구 변경, 새 글꼴·새 의존성, 측정·저장·서버 코드 변경, 범위 밖 추상화. 대사 문구를 바꿔 "뒀"을 피하는 방식은 근본 해결이 아니므로 쓰지 않는다.

`docs/memory/`, `docs/devlog/`는 고치지 않는다.

## 쓰기 범위

`client/src/ui/`, `client/src/style.css`, `scripts/e2e-play.mjs`, `docs/art/design-system.md`, `docs/art/typography.md`.

## 검사

- `npm --prefix client run typecheck`
- `npm --prefix client test`
- `npm --prefix client run build`
- `npm --prefix client run check:size`

핵심 동작 테스트 하나를 추가한다. 글꼴 로딩이 끝나지 않거나 실패해도 대사 진행이 막히지 않는지 본다.

E2E를 샌드박스에서 돌릴 수 없으면 그 사실을 적는다. 감독이 실행한다.
