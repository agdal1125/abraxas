# T018-P2 빵집 앞 한 화면 시제품

담당: agy 사용량 한도(429)로 Codex `gpt-6.1-terra`가 대체. 검수: Claude. 커밋·push 금지. 읽기 전용 셸 명령은 자유롭게 쓴다. Blender 빌드를 실제로 실행하고, 생성한 이미지를 직접 본다.

먼저 읽을 것: `docs/tasks/T018-user-brief.md`, `docs/art/immersion-policy.md`(규칙의 정본, 특히 2·4·6·7·8절), `.agents/rules/game-design-policy.md`, `.claude/skills/3dviz-abraxas/SKILL.md`.

## 사람이 정한 것 (2026-11-05)

1. 그래픽 방향은 A안이다. 현행 저폴리를 유지하고 형태·배치·명암을 정리한다. 빵집 앞 한 화면을 먼저 만들어 보여 준 뒤 확장을 결정한다.
2. 주인공은 흰 알 껍질을 유지하되 크림색 밝은 면, 옅은 회보라 음영, 깨진 껍질 경계를 보이게 한다. 얼굴·성별 단서·선택별 색은 넣지 않는다.
3. 소리와 빛 변화는 시제품 통과 뒤로 미룬다. 이번에는 넣지 않는다.

## 이번 시제품에서 고칠 것

기준 화면은 `docs/reviews/immersion/P2/before-bakery-844.png`와 `docs/reviews/immersion/2026-11-05-user-screenshot.webp`다. 빵집 두 채는 `prop-9`(6, -6.93, rot 3.142)와 `prop-10`(11, -5.20, rot 2.094)이다.

1. **길.** 빵집 앞 구간의 뾰족한 꺾임을 완만한 곡선으로 고친다. 정책의 폭·가장자리 규칙을 따른다. 보이는 길과 실제 통행 가능 구역이 어긋나지 않아야 한다.
2. **빵집.** 게임 시점에서 입구·진열창·빵이 보여 이름표 없이 빵집으로 읽혀야 한다. 먼저 회전 또는 배치로 정면을 카메라와 접근 방향으로 돌릴 수 있는지 본다. 그다음 보이는 큰 벽의 빈 면, 지붕과 벽의 경계(처마 두께·아랫면 명암)를 고친다. 정체가 모호한 큰 노란 곡면과 큰 천은 빵 간판·차양으로 읽히게 지지 구조를 주거나, 읽히지 않으면 단순화하거나 없앤다.
3. **소품 군집.** 빵 상자는 빵집 작업 영역에, 통나무는 무관한 빈 땅에서 줄인다. 같은 소품·같은 크기·같은 방향이 한 화면에 3개를 넘지 않게 한다. 심부름과 대화에 쓰이는 소품(`moka-*` 대상, 접근점)의 ID와 도달성은 건드리지 않는다.
4. **주인공.** `whitenPlayer()`를 사람 결정 2에 맞게 바꾼다. 정점 RGB를 같은 값으로 덮지 말고 원래의 AO·명암 차이를 보존한 채 흰 계열로 옮긴다. 검은 윤곽선을 두르지 않는다. 캐릭터 생성기와 `player.glb`는 바꾸지 않는다. 다른 캐릭터의 색은 그대로여야 한다.
5. **진행 표식.** `Village.label()`의 표식을 정책 4절 진행 표식 규칙에 맞춘다. 18px과 24px을 실제 화면에서 비교해 하나를 고르고 근거를 적는다. 터치 영역을 줄이지 않는다. 대화 중 화자 위 표식은 숨긴다. 모든 대상에 같은 규칙을 적용하고, 답을 암시하는 강조를 넣지 않는다.
6. **조명.** 새 광원·후처리·입자를 넣지 않는다. 필요하면 반구광과 방향광의 비율만 조정한다. 다른 화면이 나빠지지 않는지 확인한다.

측정 수치, 문항, 대사 문구, 저장, 서버 코드는 바꾸지 않는다. 시간 변화, 소리, 새 텍스처, 새 의존성은 넣지 않는다. 범위 밖 추상화를 만들지 않는다.

## 쓰기 파일

`docs/art/immersion-policy.md` 8절의 P2 행에 열거한 파일과 `docs/reviews/immersion/P2/`. 다른 파일은 쓰지 않는다. 환경 생성기는 **출력 대상을 지정해** 다른 나무·관목 GLB가 바뀌지 않게 하고, 실제로 바뀐 파일을 보고한다. `docs/memory/`, `docs/devlog/`는 고치지 않는다.

## 합격 기준

직접 이미지를 보고 판정한다. 불합격이면 고치고 다시 빌드한다.

- 빵집을 이름표 없이 빵집으로 알아볼 수 있다. 입구가 게임 시점에서 보인다.
- 길 굽이에 직선 두 개가 꺾여 만나는 뾰족한 외곽이 없다.
- 무관한 빈 땅에 빵 상자·통나무가 흩어져 있지 않다. 통행 공간이 비어 있다.
- 주인공이 백색 덩어리가 아니라 껍질 경계와 몸의 명암이 읽힌다. 게임 크기에서 자리표시자처럼 보이지 않는다.
- 표식이 대상과 연결되어 보이고 선택지 정답을 암시하지 않는다.
- 정책 6절의 예산 안이다. 환경 텍스처 추가 0개, 재질 수 증가 0개, 빵집 상한 5,000삼각형·180KiB, 지형 상한 30,000삼각형·1MiB.

## 증거

`docs/reviews/immersion/P2/`에 남긴다. 게임을 띄워 찍을 수 없으면 그 사실을 보고한다. 감독이 게임 화면으로 검수한다. Blender 프리뷰를 게임 합격 근거로 쓰지 않는다. 바꾼 공유 자산이 다른 화면에도 영향을 주므로(빵집 두 채, 지형 전체, 조명, 주인공) 영향을 받는 위치를 보고에 적는다.
