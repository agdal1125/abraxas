# T018-P2 3단계: 진행 표식과 주인공 밝기

`docs/tasks/T018-P2-bakery-prototype.md`의 사람 결정, 합격 기준, 금지 사항과 `docs/art/immersion-policy.md` 4절의 '진행 표식', '주인공' 줄이 기준이다. Codex가 대체하므로 셸 읽기는 자유롭다. 커밋·push 금지. 이 단계는 **`client/src/scenes/`만** 쓴다. 다른 작업자가 동시에 월드와 애셋을 고치므로 그쪽은 쓰지 않는다.

## 할 일

1. **주인공 밝기.** 이번 `whitenPlayer()` 결과는 껍질 경계가 살아났지만 게임에서 회색이 탁해 흰 알 껍질로 안 보인다. 밝은 면은 거의 흰 크림색, 그늘만 옅은 회보라가 되게 명도 곡선을 올린다. 평균 밝기가 충분히 높아야 하고, 그래도 껍질 경계와 몸의 명암이 남아야 한다. 값을 테스트로 고정하지 말고 "명암 차이가 남는다"와 "공유 NPC 색 불변"을 본다.
2. **진행 표식.** 지금 표식(`Village.label()`)은 큰 노란 원이다. 정책대로 18~24px로 줄이고 머리와 4~12px 간격으로 붙인다. 18px과 24px을 코드에서 쉽게 바꿀 수 있는 상수 하나로 두고, 기본값을 근거와 함께 고른다. 터치 영역을 줄이지 않는다. 대화 중 화자 위 표식은 숨기고 대화가 끝나면 돌아온다. 모든 대상에 같은 규칙을 쓴다. 답을 암시하는 강조, 반짝임, 색 차이를 넣지 않는다. 움직임 줄이기 설정을 지킨다.

## 검사

`npm --prefix client run typecheck`, `npm --prefix client test`를 실행한다. 대화 중 숨김과 복귀를 확인하는 테스트 하나를 더한다.

한국어로 바꾼 것, 고른 표식 크기와 근거, 검사 결과, 미확인 항목을 보고한다. `docs/memory/`, `docs/devlog/`는 고치지 않는다.
