# T027 사람 피드백 원문

2026-11-12, 풀 높이를 낮춘 화면(#125)을 본 뒤 사람이 준 말이다. 고치지 않고 그대로 옮긴다. T027-A·B·C의 담당은 작업 전에 이 글을 먼저 읽는다.

> 풀이 너무 띄엄띄엄 있는데, 배경을 좀 더 오픈월드 같이 다채롭게 만들어줄 수는 없나?
> 웹 브라우저 기반 게임이라는 점도 체크해서 최적화도 해주고
> 현재 핸드폰 가로 모드에서는 주소창 때문에 조작이 어려줘. 그리고 인트로 영상 버튼도 클릭이 잘 안돼. 이 부분들도 고려해서 수정해줘

- 풀잎은 발목 높이(0.05~0.09 u)를 유지한다(2026-11-12 사람 결정, #125). 인물이 걷는 곳의 풀을 다시 키우지 않는다.
- 사람이 쓰는 폰과 브라우저는 아직 모른다. T027-C는 Android와 iPhone 양쪽을 가정한다.
