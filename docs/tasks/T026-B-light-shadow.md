# T026-B 조명과 그림자

먼저 `docs/tasks/T026-user-brief.md`를 읽는다. 담당·검수 메인 세션. 브랜치 `art/light-shadow`.

## 목표

사람 피드백 4번, "그림자 조명의 디테일이 너무 부족합니다. 조명도 너무 일직선이에요"를 푼다. 740×360 화면에서 건물·나무·인물의 그림자가 땅에 보이고, 보이는 두 벽면의 밝기가 다르고, 빛이 고르게 깔리지 않고 시간에 따라 달라진다.

## 원인

방향광이 카메라와 같은 쪽에 있었다. 빛 위치는 주인공 + (4, 10, 5)이고 카메라는 +x+z에서 본다. 그림자가 물체 뒤로 떨어져 화면에 보이지 않았고, 보이는 두 벽면의 입사각이 0.34와 0.42로 거의 같아 면이 구분되지 않았다.

## 바꾼 것

| 항목 | 전 | 후 |
| --- | --- | --- |
| 해 방향(장면 → 해) | (4, 10, 5), 고도 57°, 카메라 쪽 | (-3.2, 5.6, 5.3), 고도 42°, 화면 왼쪽 |
| 방향광 | `#fff0df` 2.9 | `#fff1dc` 3.05 |
| 반구광 | 하늘 `#fff4ed`, 땅 `#e8ddf4`, 0.75 | 하늘 `#eceefc`, 땅 `#f1e3d2`, 1.05 |
| 환경광 | 0.05 | 없음(반구광에 합침) |
| 그림자 가장자리 | 반경 기본값 | `shadow.radius` 2.2 |
| 그림자 영역 반폭 | `max(4, h × (a + 1) × 1.1)` | `max(3, h × max(a, 1.75) × 1.15)` |
| 그림자 카메라 이동 | 주인공을 그대로 따라감 | 그림자 텍셀 단위로 맞춰 이동 |
| 구름 그늘 | 없음 | 화면에 곱하는 평면 한 장, 천천히 흐름 |

- 그림자 영역을 보이는 땅 크기에 맞춰 좁혔다. 같은 1024 맵에서 해상도가 740×360 기준 약 1.4배가 된다. 그림자 맵 상한과 광원 수는 그대로다.
- 그림자 카메라를 텍셀 단위로 움직여 걸을 때 그림자 가장자리가 흔들리지 않게 했다.
- 구름 그늘은 깊이 검사 없이 불투명 장면 위에 곱한다. 땅과 그 위의 나무·벽이 함께 어두워진다. 표식과 입자보다 먼저 그려 표식 밝기는 그대로다. `prefers-reduced-motion`이면 흐름을 멈춘다.
- 코드는 `client/src/scenes/light-rig.ts`에 모았다. `village.ts`에는 생성, 크기 변경, 갱신 세 줄만 남는다.

## 지키는 것

- 그림자를 드리우는 광원 1개, 그림자 맵 최대 1024(모바일), 후처리 없음(`docs/art/immersion-policy.md`).
- 구름 그늘은 시간으로만 움직인다. 선택 화면이나 선택 결과에 반응하지 않는다.
- 인물 재질과 주인공의 흰색은 건드리지 않는다.
