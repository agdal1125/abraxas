# T013 사람 요청 원문 — 실기기 피드백과 역할 변경 (2026-11-01)

아래는 사람이 실기기(휴대폰)에서 확인한 뒤 남긴 요청 원문이다. 모든 에이전트(Codex Astra, agy Argon4)는 이 문서를 그대로 기준으로 삼는다.

> 몇 가지 수정 사항이 있어:
> 1. 초기에 화면 버벅임이 있음
> 2. 배경에 눈, 꽃잎이 흩날리는게 고정되어 있어서 움직일 때 같이 따라 움직여서 화면에 뭐가 묻은 것 처럼 보여
> 3. 가로로 돌렸을 때, 브라우저 상단 주소창이 보여서 몰입에 좀 방해가 되. 그리고 화면비가 고정이라서 양 옆이 짤리는 부분이 생겨. 모든 기기에서 게임을 꽉 채워서 보여주고 싶음
> 4. 상호작용은 examine이 아니라, 일정 거리상에 있을 때 터치를 하는 것으로 대체하고 싶어 (examine 버튼 전부 제거)
> 5. 화살표 및 이동 방향키/조이스틱은 기본적으로 숨김처리를 하고, 조작할 때만 반투명하게 나타나는 식으로 UI 수정해줘.
>
> 위의 수정사항 전부 반영한 다음에는 개발 일지에 업데이트 하고, 다음 개발해야하는 내용에 대해서 정리해줘. 기본적인 agenda만 파악할 수 있게 사람이 이해하기 쉬운 형태로 쉽게 써놔.
>
> agy, codex cli 사용해서 진행하고 전반적인 게임 개발 계획, 디자인은 Astra High 로 시키고 실제 개발 작업 및 디자인 아트 애셋 생성은 Argon4로 진행해. 프로젝트 정책파일 업데이트 잊지말고.

## 감독 메모
- 테스트 환경: 사람이 PC와 같은 Wi-Fi에서 `vite preview --host`로 띄운 배포 빌드를 휴대폰 가로 화면으로 확인함.
- 역할 변경: 계획·디자인 = Codex `gpt-6-astra` (reasoning high), 실제 개발·아트 애셋 = agy `gemini-4-argon-medium`. Claude는 지휘·검수·병합.

## 사람 결정 (2026-11-01, Astra 계획 질문에 대한 답)
- 거리 밖 대상을 탭하면: **자동으로 걸어가서 도착하면 상호작용** (Astra 추천안 '안내만 표시'가 아니라 사람이 이 안을 선택함). 계획서 §4의 거리 밖 동작은 이 결정으로 대체한다.
- 데스크톱 키보드: **Space·Enter 유지 + E 추가**로 가장 가까운 대상과 상호작용.
- iPhone 등 전체 화면 미지원 환경: **닫을 수 있는 '홈 화면에 추가' 안내**, 홈 화면 실행 지원, 일반 탭 플레이도 허용.
