# 모카 — 따뜻할 때 전하는 것

## 목적·감정선

빵을 돌보며 서로 다른 배려를 본다. 조심스러운 만남이 편안한 일손으로 이어진다.

## 장소·등장인물

빵집, 언덕 위 공방. 주인공, 모카, 시식 안내인, 단골 손님, 지친 이웃.
