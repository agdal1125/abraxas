## 요약

| 항목 | 내용 |
| --- | --- |
| 장르 | 내러티브 어드벤처 + 데이트 심 + 라이트 퍼즐 |
| 플랫폼 | 모바일 웹, 링크로 즉시 실행, 세로 고정 |
| 플레이 타임 | 1회 약 31분 |
| 결과 | 16유형 + 수식어, 고백 대상의 최종 유형, 공유 카드 3장 |
| 구조 | 프롤로그 → 캐릭터 에피소드 4개(순서 자유) + 막간 3 → 축제 → 기억의 문 → 고백 → 결과 |
| 바이럴 | 재플레이에 초대권 1장, 공유 시 즉시 지급, 인당 최대 8장 |
| 수익 | 무료 + 광고 |

측정·수치 규칙은 `.agents/rules/game-design-policy.md`에 따로 정리돼 있다. 기획서를 고치면 그 파일도 맞춰 고친다.
