# RS1-W 월드 연결 인계

- 세 주민의 view setter와 resume은 기존 계약을 유지한다. UI 연결은 별도 통합 worktree에서 완료되어 병합 대기 중이다.
- 주민 소품 충돌체는 각 view 적용 후 실제 모델과 상위 그룹의 표시 상태에 맞춰 다시 구성한다. 숨겨진 소품은 충돌하지 않고 완료 장식은 표시되는 동안 남으며, 주민 actor 충돌체는 유지한다. 활성 소품이 숨겨지거나 누락되면 오류를 낸다.
- 실제 `Village`·`ResidentProps` 회귀 테스트는 세 주민 각각에 대해 충돌체 중복 방지, 단계 전환, 완료 장식, null 복원 및 상위 그룹 숨김을 확인한다. 실패한 에셋 로드 캐시의 재시도 동작은 유지했다.
- 검증: 클라이언트 타입 검사, 집중 테스트 17개, `node scripts/check-village-reach.mjs` 통과. 도달성 검사는 모든 소품이 존재하는 보수적 조건을 유지한다.
