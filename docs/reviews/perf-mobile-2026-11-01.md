# 모바일 에뮬레이션 성능 측정 — 2026-11-01

실제 폰 측정이 아닌 이 컴퓨터의 Edge 헤드리스 CDP 에뮬레이션 결과다. 배포 빌드를 Vite preview로 제공하고 빈 브라우저 프로필을 사용했다. 390×844, DPR 2, 터치, CPU 4배 감속, Fast 3G 수준(지연 150ms, 다운로드 1.6Mbps, 업로드 750Kbps)이다. 렌더러는 모바일 픽셀 비율을 1.5로 제한한다. SwiftShader 소프트웨어 렌더링을 사용했으므로 FPS는 실제 모바일 GPU 성능을 나타내지 않는다.

FCP는 브라우저의 첫 콘텐츠 표시다. 마을 UI 및 자산 요청 완료 시간은 타이틀과 프롤로그 자동 클릭, 이동 UI 표시와 시작된 자산 요청 완료까지 포함한다. 내부 자산 준비 상태를 직접 확인한 값은 아니다. 전송량은 해당 시점까지 완료된 요청의 CDP encodedDataLength 합계다. FPS는 터치 이동 입력을 유지한 10초의 requestAnimationFrame 횟수이며 화면 변화를 확인했다. 배포 빌드에는 개발용 위치 훅이 없어 위치 변화는 직접 검증하지 않았다. 힙은 이동 입력 직후 CDP JSHeapUsedSize다.

| 항목 | 측정값 |
| --- | ---: |
| 첫 콘텐츠 표시 (FCP) | 1.84초 |
| 시작부터 마을 UI와 자산 요청 완료까지 | 6.47초 |
| 해당 시점까지 전송량 | 1.08 MiB (1,134,269 bytes) |
| 이동 입력 중 평균 FPS (10초) | 21.6 |
| 이동 입력 후 JS 힙 사용량 | 13.20 MiB |

이전 개발 서버 참고값: FCP 39.55초, 마을 조작 가능 44.59초, 전송량 8.57 MiB, FPS 21.9, JS 힙 33.06 MiB. 준비 판정이 달라 직접 비교에는 주의한다.

실행: `npm --prefix client run build` 후 client 디렉터리에서 `npx vite preview --host 127.0.0.1 --port 4173`, 별도 터미널에서 저장소 루트 기준 `node client/scripts/perf-mobile.mjs 4173`.
