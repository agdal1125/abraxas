# 모바일 에뮬레이션 성능 측정 — 2026-11-01

실제 폰 측정이 아닌 이 컴퓨터의 Edge 헤드리스 CDP 에뮬레이션 결과다. 개발 서버와 빈 브라우저 프로필을 사용했다. 390×844, DPR 2, 터치, CPU 4배 감속, Fast 3G 수준(지연 150ms, 다운로드 1.6Mbps, 업로드 750Kbps)으로 측정했다. 렌더러는 모바일에서 자체적으로 픽셀 비율을 1.5로 제한한다. GPU 프로세스가 실행 환경에서 종료되어 SwiftShader 소프트웨어 렌더링을 사용했으므로 FPS는 실제 모바일 GPU 성능을 나타내지 않는다.

첫 화면은 브라우저 FCP다. 조작 가능 시간은 타이틀부터 프롤로그를 자동 클릭하고 마을 자산 로드 및 이동 UI 준비까지의 시간으로, 자동 클릭 간격과 이야기 길이를 포함한다. 전송량은 그 시점까지 완료된 요청의 CDP encodedDataLength 합계다. FPS는 터치 이동 입력을 유지한 10초의 requestAnimationFrame 횟수이며 실제 위치 변화도 확인했다. 힙은 이동 직후 CDP JSHeapUsedSize다. 개발 서버의 모듈 전송량은 배포 빌드와 다르다.

| 항목 | 측정값 |
| --- | ---: |
| 첫 콘텐츠 표시 (FCP) | 39.55초 |
| 시작부터 마을 조작 가능까지 | 44.59초 |
| 조작 가능까지 전송량 | 8.57 MiB (8,986,276 bytes) |
| 이동 중 평균 FPS (10초) | 21.9 |
| 이동 후 JS 힙 사용량 | 33.06 MiB |

실행: `npm --prefix client run dev` 후 `node client/scripts/perf-mobile.mjs 5173`.
