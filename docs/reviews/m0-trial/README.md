## M1에 넘기는 항목

메인이 직접 확인한 것:

1. moka_02 반응이 고른 선택과 뒤바뀌어 읽힌다. 다른 NPC 문항에도 같은 문제가 있는지 전수 검사한다.
2. 공유 텍스트에 링크가 없고, 카드 2·3 공유가 NPC 성향과 줄거리를 내보낸다.
3. 영상 뒤 대사 21줄과 이름 입력을 지나야 첫 선택이 나온다.
4. 렌더 calls는 한 장면에서 119다. 인스턴싱보다 실제 폰 측정이 먼저다.

subagent 보고이며 메인이 다시 확인하지 않은 것:

5. 모카 에피소드 챕터 문서의 재미 12줄이 ink에 없다. 어느 쪽이 정본인지 사람이 정한다.
6. moka_01·02·06 문구가 모카의 기대 극 쪽으로 쏠린다. 문구 변경은 사람 승인 사항이다.

아직 안 한 것: 그래픽 게이트 시험, 비평 재시험(앱 창을 띄운 상태 또는 playwright), 대화 뒤 목표와 이동 확인, 새 세션의 agent 호출 확인.
