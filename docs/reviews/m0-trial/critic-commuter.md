# M0 시험: 첫 구간 플레이 (critic-reviewer, commuter)

2026-11-08 · 기준 #90 · 일반 subagent가 역할 파일과 `critic-playtest`를 읽고 수행.

**이 보고는 기준선으로 쓰지 않는다.** 시험 환경에 문제가 두 가지 있었다. 메인이 확인했다.

1. 개발 서버만 띄워 API가 없었다. `/v1` 요청이 8080에 있던 다른 세션의 서버로 프록시됐다. '연결되면 이어갈 수 있어요'에 갇힌 것은 이 환경 탓으로 본다. 이후 `scripts/dev-play.mjs`를 만들었다.
2. 브라우저 패널이 숨겨져 있었다. 3D 장면이 돌지 않고 캡처가 잘려 화면 아래쪽의 선택지가 보이지 않을 수 있다. 조작감, 이동, 목표 표시 지적은 믿을 수 없다.

## 메인이 올바른 서버로 다시 확인한 것

DOM으로 대사를 넘겨 확인했다. 화면과 조작감은 확인하지 못했다.

| 지적 | 확인 결과 |
| --- | --- |
| 첫 선택까지 탭만 한다 | **사실.** 영상 뒤 대사 21줄과 이름 입력을 지나야 첫 선택지(광장 또는 호숫가)가 나온다. 그 뒤 5줄 뒤에 둘째 선택지가 나온다 |
| 오프닝 영상에 글이 없고 길다 | 영상 길이 51초는 문서와 일치. 캡션 없음은 비평가 관찰이고 나는 재지 않았다. 건너뛰기 버튼은 있다 |
| '로컬 체험' 알약이 버튼처럼 보인다 | 제목 화면에 큰 주황색 알약으로 나온다. 개발 모드 문구이므로 운영 빌드에서는 다시 본다 |
| 연결 화면에 갇힘 | 환경 문제로 본다. 서버가 실제로 끊겼을 때의 복구는 M1에서 다시 본다 |
| 대화 뒤 목표와 이동을 못 찾음 | **미확인.** 첫 탐색 상태까지 가지 않았다. M1 재시험 대상 |
| 지문과 화면이 어긋남 | **미확인.** 장면이 멈춘 상태의 관찰이다 |

## 비평가가 남긴 말 중 쓸 만한 것 (재미 평가는 추정)

- 첫 60초: 제목의 '기억을 잃은 채 낯선 마을에서 눈을 떴다'로 설정은 이해했다. 영상은 줄거리가 읽히지 않았다.
- 심리테스트로 들어왔는데 3분 안에 내가 고르는 순간이 없었다.
- 기억에 남은 것: "알에서 깬 것 같은 아이가 강아지랑 마을에 떨어졌는데, 우체부가 '하늘에서 왔냐'고 묻는다."
- 좋았던 것: 우체부의 "혹시 하늘에서 왔나? / 그럴지도 몰라." 주고받음.

## 역할 시험에서 배운 것

- 플레이 환경을 메인이 준비하고 숨김 여부를 확인해야 한다. 스킬에 반영했다.
- 호출 80회 제한은 영상과 대사 탭으로 소모돼 첫 에피소드까지 못 간다. 전체 플레이는 호출 수를 크게 잡고 페르소나별로 구간을 나눈다.
- 숨김 없는 브라우저가 필요하다. 사용자가 앱을 띄워 두거나, 자체 브라우저를 쓰는 `playwright` 플러그인을 쓴다.
- subagent가 패널을 혼자 쓰므로 비평가는 한 번에 한 명만 돌린다.
