# T014 UI·UX 검토 (감독 검수, 2026-11-02)

대상: main `7f11504` (T013 반영 후). 확인 방법: 헤드리스 Edge 모바일 에뮬레이션 844×390·932×430에서 처음부터 결과까지 한 회차 진행, 터치 탭·조이스틱 조작. 캡처는 `docs/reviews/T014-uiux/`.
실기기 확인은 아직 하지 않았다. 아래 항목은 화면 캡처와 조작 결과에서 확인한 것만 적었다.

## 잘 된 점
- 가로 화면을 꽉 채우고, 조작부가 평소에 숨어 있어 마을이 잘 보인다.
- 대사창이 화면 아래 가운데에 놓여 시선 이동이 적다.
- 먼 주민을 탭하면 집을 돌아 걸어가 대화가 열린다.

## 글꼴 선정 조건 (사람 요청: 한국어·영어를 모두 지원하는 가장 알맞은 글꼴)
- 한글·라틴 모두 포함, 웹 배포 가능한 자유 라이선스(OFL 등), 상업적 사용 가능.
- 파스텔·꿈같은 분위기와 어울리되 작은 글씨(14~16px) 대사에서 잘 읽힐 것.
- 자체 호스팅(woff2), 첫 화면 로딩에 부담이 적은 용량. 새 외부 서비스 연결은 하지 않는다.
- 제목용 장식 글꼴을 따로 쓸지는 선택. 쓰면 용량과 근거를 적는다.
