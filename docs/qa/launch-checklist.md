# 출시 점검표

스테이징에서 운영으로 넘어가기 전에 이 파일을 복사해 `docs/qa/releases/YYYY-MM-DD-<커밋>.md`로 저장하고 채운다. 모바일 웹, 무료, 서버 판정 구조에 맞춘 목록이라 콘솔 인증, 스토어 페이지, 멀티플레이는 넣지 않았다.

## 표기

| 표기 | 뜻 |
| --- | --- |
| `[x]` | 확인함. 줄 끝에 근거를 적는다(PR, 로그, 스크린샷, 플레이테스트 기록) |
| `[ ]` | 확인했더니 아직 안 됨 |
| `[?]` | 아무도 확인하지 못함 |
| `N/A` | 이번 출시에 해당 없음. 이유를 적는다 |

## 1. 빌드와 자동 검사

- [ ] `npm --prefix client run typecheck`
- [ ] `npm --prefix client test`
- [ ] `npm --prefix client run build`, `npm --prefix client run check:size` (게임 10MB, 영상 13MB 이내)
- [ ] `npm --prefix client audit --omit=dev --audit-level=high`
- [ ] 서버 `gofmt -l .`, `go vet ./...`, `go test ./...`, `govulncheck ./...`
- [ ] `npm run check:scoring`
- [ ] `node client/scripts/check-abraxas-assets.mjs`, `check-dialogue.mjs`, `check-visible-names.mjs`
- [ ] `npm run e2e:play -- --emulators ko`, `npm run e2e:play -- --emulators en` 결과까지 통과
- [ ] E2E 결과 화면 캡처를 눈으로 확인. 캡처 이름이 실제 화면과 어긋날 수 있다
- [ ] main CI 전체 통과, 대상 커밋이 main에 있음
- [ ] 남은 `TODO`, `FIXME` 수: 파일 ___개 중 ___건, 각각 출시 영향 판단

## 2. 측정 무결성

기준: `.agents/rules/game-design-policy.md`

- [ ] 측정 문항 38개와 타이브레이커 4개가 한 회차에 빠짐없이 나옴
- [ ] 선택 즉시 서버에 확정되고, 새로고침과 뒤로 가기로 다시 고를 수 없음
- [ ] NPC 반응은 공감과 생각에 잠김 두 종류뿐이고, 하트는 에피소드 끝에만 나옴
- [ ] 선택지 문구, 색, 순서, 데미의 움직임이 기대 답변을 암시하지 않음
- [ ] 플레이어 화면에 축 이름, 내부 코드, 성향 수치, 호감도 숫자, 'MBTI'가 없음 (ko, en)
- [ ] 퍼즐 성공 여부와 고백 대상이 점수에 들어가지 않음
- [ ] 결과 카드 3장에 "재미로 보는 심리 게임" 고지가 있고, 1회차 결과가 '처음의 나'로 보관됨
- [ ] TS와 Go 골든 테스트가 같은 결과를 냄
- [ ] 이번 출시의 수치, 문항, 초대권 변경에 사람 승인 기록이 있음 (`docs/memory/decisions.md`)

## 3. 보안과 신뢰 경계

기준: `.agents/rules/security.md`

- [ ] 운영 환경에 `ABRAXAS_DEV_FAKE_AUTH`, `ABRAXAS_DEV_SKIP_APP_CHECK`, `VITE_ABRAXAS_DEV_FAKE_AUTH`가 없음
- [ ] 토큰 없는 요청과 App Check 토큰 없는 요청이 실제 주소에서 거절됨
- [ ] 다른 사람의 회차 ID로 조회와 명령이 거절됨
- [ ] Firestore 규칙이 클라이언트 읽기와 쓰기를 모두 거부함
- [ ] 초대권 발급과 소모, 결과 저장을 서버만 판정함
- [ ] uid별 요청 제한이 동작함(HTTP 429 확인)
- [ ] Cloud Run 서비스 계정 권한이 필요한 최소 범위임
- [ ] CSP, HSTS, `nosniff`, `Referrer-Policy` 헤더가 실제 응답에 있고, 콘솔에 CSP 위반이 없음
- [ ] Firebase 웹 키와 reCAPTCHA 키의 허용 도메인을 제한함
- [ ] 저장소와 번들에 비밀값이 없음(gitleaks 통과)
- [ ] 플레이어 이름이 서버로 전송되지 않음

## 4. 콘텐츠와 권리

- [ ] 한국어와 영어 대사를 끝까지 교정함, 글자가 UI 안에 들어감
- [ ] 임시 문구와 자리표시 그림이 없음
- [ ] 16유형 이름과 결과 일러스트가 확정됨
- [ ] 음악과 효과음의 개별 출처, 라이선스를 게임 안 출처 표기에 넣음
- [ ] 외부 에셋 출처 표기가 빠지지 않음. CC BY 메시는 모델별로, 재배포 금지 파일은 저장소에 없음
- [ ] 게임명과 마케팅 문구에 상표 문제가 없음

## 6. 서비스 흐름

- [ ] 1회차는 무료이고, 재플레이는 초대권 1장을 소모함
- [ ] 초대 링크 공유가 끝날 때마다 1장 지급, 인당 평생 최대 8장을 서버가 지킴
- [ ] 엔딩 뒤 다시 시작 버튼이 막다른 길 없이 초대권 흐름으로 이어짐
- [ ] 결과 공유 화면과 링크 미리보기가 동작함
- [ ] 광고를 넣는다면 승인과 노출 위치가 확정되었고, 측정 선택 중에는 나오지 않음
- [ ] 개인정보 처리방침을 게시함. 익명 uid, 선택 로그, 결과, 초대권, 유입 경로 저장을 설명함
- [ ] 이용 조건과 데이터 삭제 요청 창구를 안내함. 법적 판단은 사람이 전문가와 확인함

## 7. 운영

- [ ] 운영 프로젝트가 스테이징과 분리되어 있음
- [ ] 예산 알림, Cloud Run 최대 인스턴스 수를 설정함
- [ ] 오류 로그를 볼 수 있고, 오류 증가 알림이 옴
- [ ] Firestore 백업 또는 보존 정책을 정함
- [ ] 클라이언트와 서버를 같은 콘텐츠 버전으로 함께 배포함
- [ ] 직전 Hosting 릴리스와 Cloud Run 리비전으로 함께 되돌리는 절차를 실제로 해 봄
- [ ] 진행 중인 회차가 있을 때 콘텐츠 버전을 올리면 어떻게 되는지 확인함
- [ ] 출시 첫날 문제를 받을 창구와 공지 위치를 정함

## 출시 판단

위에서 처음 맞는 줄이 판단이다.

1. **보류:** 차단 항목이 있음
2. **판단 불가:** `[?]`가 남아 있음. 확인 못 한 것은 통과가 아니다
3. **조건부:** 위험을 수용한 항목만 남음
4. **가능:** 모두 `[x]` 또는 `N/A`

- 판단:
- 차단 항목:
- 수용한 위험과 수용한 사람:
- 운영 배포 승인: 사람 이름과 날짜. 에이전트는 이 칸을 채우지 않는다
