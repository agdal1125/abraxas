# 기능 QA 보고서

qa-engineer가 쓴다. 양식과 절차는 `.agents/skills/qa-check/SKILL.md`에 있다.

- 파일 이름: `YYYY-MM-DD-<대상>.md` (대상은 PR 번호, 브랜치, 구간 이름)
- 스크린샷과 E2E 출력은 `.e2e/`(git 제외)에 두고 경로만 쓴다
- 회귀 확인은 원래 보고서의 결함 아래에 덧붙인다

보고서가 아닌 고정 양식도 이 폴더에 둔다. 플레이테스트 기록은 `playtest-template.md`를 복사해 `playtests/`에, 운영 전 점검은 `launch-checklist.md`를 복사해 `releases/`에 저장한다.
