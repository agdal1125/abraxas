# 디자인 시스템

레퍼런스: 모여봐요 동물의 숲. **에셋·폰트·아이콘·캐릭터를 복제하지 않는다**(닌텐도 저작권·상표). 그 게임에서 읽어 낸 디자인 *원칙*을 우리 말로 정리하고, 토큰·컴포넌트는 우리가 새로 만든다. 마지막 절이 Abraxas 의도에 맞춘 튜닝이다.

## 1. 레퍼런스에서 읽은 원칙

| 원칙 | 레퍼런스에서 보이는 것 | 우리 시스템에서의 뜻 |
| --- | --- | --- |
| 손에 잡히는 물건 | 창과 버튼이 마을의 물건처럼 두툼하다 | 누르는 것은 나무 표지판, 읽는 것은 크림색 종이. 모서리는 둥글리지 않고 비스듬히 자르며 아래에 어두운 턱을 둔다 |
| 세상이 주인공 | UI는 작고 화면 가장자리에 붙는다. 대사창도 화면 아래 낮게 | UI가 화면의 40%를 넘지 않는다. 측정 선택지 화면도 같다. 말하는 인물을 가리지 않는다 |
| 말하는 사람이 색으로 보인다 | 말풍선 왼쪽 위 이름표가 캐릭터마다 다른 색 | 화자 이름 태그 = 캐릭터 대표색 |
| 따뜻한 종이 질감 | 순백이 아닌 크림·아이보리 바탕, 진한 갈색 글자 | 바탕 `#F6EAD0`, 글자 `#3B2A22` (순흑·순백 금지) |
| 손으로 넘기는 대화 | 버튼 없이 탭하면 다음 줄, 작은 깜빡이는 화살표 | ▼ 표시, 대사창 전체가 탭 영역 |
| 고르는 순간에 시선을 모은다 | 대사창 위·옆에 작게 쌓이는 선택지 | 화면 정중앙에 같은 폭의 나무 표지판을 세로로 쌓고, 상황 글은 그 아래 종이에 둔다 |
| 통통 튀는 움직임 | 등장할 때 살짝 커졌다 줄어드는 탄성 | 등장 200ms 탄성(overshoot), 누르면 2px 내려가고 턱이 얇아진다 |
| 섬 하나가 세계 | 바다로 둘러싸인 섬, 가장자리가 자연스럽다 | 마을을 바다 링으로 감싼 섬, 화면에 빈 하늘이 보이지 않게 |
| 낮은 대비의 자연, 높은 대비의 포인트 | 풀·길은 차분하고 지붕·꽃·캐릭터가 선명 | 환경 채도는 중간, 캐릭터·표식만 강한 색 |

### 모양·간격·움직임

| 토큰 | 값 |
| --- | --- |
| 모서리 | 둥글리지 않는다. 버튼·창·목표·메뉴는 8px, 이름 태그·수식어는 4px로 비스듬히 자른다. 원형은 이동 패드와 진행 표식뿐이다 |
| 간격 | 4 · 8 · 12 · 16 · 24 |
| 턱 | 아래쪽 안쪽 4px(`inset 0 -4px 0`). 버튼은 `wood-edge`·`plank-edge`, 종이는 `paper-edge`. 떠 있는 그림자 `0 6px 18px rgba(59,42,34,.18)`는 진행 표식에만 쓴다 |
| 터치 영역 | 최소 48×48px. 모서리를 잘라도 안쪽 48px은 그대로 눌린다 |
| 등장 | 200ms, 탄성 곡선 `cubic-bezier(.34,1.56,.64,1)` |
| 누름 | 2px 아래로, 턱 4px→2px, 80ms. 움직임 줄이기에서는 끈다 |
| 포커스 | 바깥이 잘려 나가므로 버튼 안쪽에 3px 선을 그린다. 나무 위 `marker`, 판자 위 `wood-edge`, 종이 위 `wood` |

## 3. 컴포넌트

| 컴포넌트 | 규칙 |
| --- | --- |
| 대사창 | 종이. 화면 아래, 좌우 12px, 최대 폭 420px, 높이는 내용만큼(최대 38%). 이름 태그는 창 안 왼쪽 위 첫 줄. 선택지가 없으면 오른쪽 아래에 ▼, 탭으로 넘긴다 |
| 이름 태그 | 4px로 자른 모서리, `label`. 바탕은 캐릭터 대표색, 글자는 주민이면 `ink`, 퀘스트 NPC면 `paper` |
| 선택지 | 화면 정중앙. 폭은 `min(본문 글자 × 29, 화면 폭)`(17px에서 493px, 20px에서 580px). 나무 표지판을 8px 간격으로 세로로 쌓고, 모두 같은 폭·색·글자 크기로 왼쪽 정렬한다. 순서는 데이터 그대로다. 상황 글(대사창)은 같은 폭으로 그 아래에 두고 최대 `40vh - 12px`, 넘치면 안에서 스크롤한다. 카메라는 화자와 주인공의 발이 선택지 위 8px에 오도록 맞춘다. 740×360·844×390 기본 글자에서 UI 40% 이하 |
| 타이틀 | 게임 이름은 나무 판(`wood`, 글자 `wood-text`). 아래에 시작(판자, 한 줄 전체 폭)과 나무 보조 버튼: 언어, 글자 크기, 화면 가득 즐기기(아이폰·인앱 브라우저에서만) |
| 결과 카드 | 가운데, 최대 폭 760px 두 단 종이. 수식어는 판자색 4px 모서리 태그, 축 문구는 점 목록, 고지는 `caption` |
| 진행 표식 | 대상 머리 위 `marker` 원 + `ink` '!' , 위아래로 천천히 떠다님 |
| 마을 지도 | 오른쪽 위 설정 버튼 왼쪽의 48px '지도' 표지판. 게임 화면과 같은 방향으로 그린다. 지금 있는 곳(판자색 원), 가 볼 곳(노란 마름모, 나무 테두리), 구역 이름만 보여 주고 주민 이름이나 관계 정보는 넣지 않는다. 색과 모양을 함께 다르게 하고 범례를 글자로 적는다 |
| 시작 전 화면 | 페이지, 로딩, 의도 문구는 `night` 바탕에 `wood-text` 글자. 크림색은 게임 안 종이에만 쓴다 |
| 이동 안내 | 처음 마을에 들어설 때 한 번, 화면 아래 가운데 종이 띠. 입력 방식에 맞는 한 줄을 쓰고, 아무 입력이나 들어오면 사라진다 |

## 환경 표현 갱신 (2026-11-05)

환경(건물·소품·식생·지면)은 사람 결정에 따라 몽환 파스텔 대신 각진 저폴리로 간다. 면이 보이는 플랫 셰이딩, 재료 색, 부재 단위 형태, 또렷한 한 방향 빛을 쓴다. 인물의 대표색과 UI 토큰은 그대로다. 근거는 `docs/art/immersion-policy.md`.
