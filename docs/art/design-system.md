# 디자인 시스템

레퍼런스: 모여봐요 동물의 숲. **에셋·폰트·아이콘·캐릭터를 복제하지 않는다**(닌텐도 저작권·상표). 그 게임에서 읽어 낸 디자인 *원칙*을 우리 말로 정리하고, 토큰·컴포넌트는 우리가 새로 만든다. 마지막 절이 Abraxas 의도에 맞춘 튜닝이다.

## 1. 레퍼런스에서 읽은 원칙

| 원칙 | 레퍼런스에서 보이는 것 | 우리 시스템에서의 뜻 |
| --- | --- | --- |
| 모서리가 없다 | 창·버튼·말풍선·아이콘이 모두 크게 둥글다 | 모든 UI 반경 ≥ 14px, 버튼은 알약형 |
| 세상이 주인공 | UI는 작고 화면 가장자리에 붙는다. 대사창도 화면 아래 낮게 | UI가 화면의 40%를 넘지 않는다 |
| 말하는 사람이 색으로 보인다 | 말풍선 왼쪽 위 이름표가 캐릭터마다 다른 색 | 화자 이름 태그 = 캐릭터 대표색 |
| 따뜻한 종이 질감 | 순백이 아닌 크림·아이보리 바탕, 진한 갈색 글자 | 바탕 `#FFF8EC`, 글자 `#3B2A22` (순흑·순백 금지) |
| 손으로 넘기는 대화 | 버튼 없이 탭하면 다음 줄, 작은 깜빡이는 화살표 | ▼ 표시, 대사창 전체가 탭 영역 |
| 선택지는 말풍선 옆에 | 대사창 위·옆에 작게 쌓이는 선택지 | 오른쪽 정렬 알약 버튼 세로 쌓기 |
| 통통 튀는 움직임 | 등장할 때 살짝 커졌다 줄어드는 탄성 | 등장 200ms 탄성(overshoot), 누를 때 96% 축소 |
| 섬 하나가 세계 | 바다로 둘러싸인 섬, 가장자리가 자연스럽다 | 마을을 바다 링으로 감싼 섬, 화면에 빈 하늘이 보이지 않게 |
| 낮은 대비의 자연, 높은 대비의 포인트 | 풀·길은 차분하고 지붕·꽃·캐릭터가 선명 | 환경 채도는 중간, 캐릭터·표식만 강한 색 |

## 2. 토큰

### 색

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `paper` | `#FFF8EC` | 대사창·카드 바탕 |
| `ink` | `#3B2A22` | 본문 글자 (paper 대비 4.5:1 이상) |
| `ink-soft` | `#8A7565` | 보조 글자, 고지 |
| `line` | `#F2B35E` | 테두리 |
| `accent` | `#FF7A59` | 주요 버튼(시작 등) |
| `marker` | `#FFD23F` | 진행 표식(!) |
| `sea` | `#5BC0F8` | 바다·배경 |
| `grass` / `grass-shade` | `#5CC96B` / `#3A9E57` | 풀 |
| `path` | `#F2B35E` | 흙길 |
| `roof` | `#FF6B5B` | 지붕 포인트 |
| `flower` | `#FF7EB6` | 꽃 |
| `char-A·B·C·D` | `#FF7A59` · `#FFB020` · `#8E6BFF` · `#14B8A6` | 공략 캐릭터, 이름 태그 |
| `char-npc` | `#3B2A22` | 퀘스트 NPC 이름 태그 |

### 글자 (시스템 폰트, 외부 폰트 없음)

| 토큰 | 크기 / 굵기 | 용도 |
| --- | --- | --- |
| `title` | 28px / 800 | 게임 이름 |
| `heading` | 18px / 700 | 결과 제목 |
| `body` | 15px / 400, 줄 간격 1.55 | 대사·선택지 |
| `label` | 12px / 700 | 이름 태그 |
| `caption` | 12px / 400 | 고지 |

### 모양·간격·움직임

| 토큰 | 값 |
| --- | --- |
| 반경 | 창 18px, 버튼·태그 999px(알약) |
| 간격 | 4 · 8 · 12 · 16 · 24 |
| 그림자 | `0 6px 18px rgba(59,42,34,.18)` 하나만 |
| 터치 영역 | 최소 48px 높이 |
| 등장 | 200ms, 탄성 곡선 `cubic-bezier(.34,1.56,.64,1)` |
| 누름 | 96% 축소 80ms |

## 3. 컴포넌트

| 컴포넌트 | 규칙 |
| --- | --- |
| 대사창 | 화면 아래, 좌우 12px, 최대 폭 420px, 높이는 내용만큼(최대 38%). 이름 태그가 왼쪽 위 모서리에 걸침. 선택지 없으면 오른쪽 아래 ▼, 탭으로 넘김 |
| 이름 태그 | 알약, `label`, 흰 글자, 바탕 = 캐릭터 대표색 |
| 선택지 | 가로 화면 하단에서 설명 오른쪽에 같은 폭으로 세로 배치, 흰 바탕·`line` 테두리 알약. 긴 내용은 내부 스크롤 |
| 타이틀 | 큰 카드 없음. 위쪽에 게임 이름(흰 글자 + 그림자), 아래에 시작(`accent`)·언어(흰) 알약 버튼 |
| 결과 카드 | 가운데, 최대 폭 360px, 수식어는 `accent` 알약, 축 문구는 점 목록, 고지는 `caption` |
| 진행 표식 | 대상 머리 위 `marker` 원 + `ink` '!' , 위아래로 천천히 떠다님 |

## 4. 월드

| 항목 | 규칙 |
| --- | --- |
| 카메라 | 정사영 쿼터뷰, 16:9 기준 가로 중심과 긴 가로 화면 대응. 모바일 세로는 회전 안내 |
| 섬 | 마을 바깥을 바다 헥스 2칸 이상으로 감싸 어디서도 빈 하늘이 보이지 않게 |
| 캐릭터 | 3등신에 가깝게, 점 눈 + 작은 입, 실루엣으로 구분(A 공·B 물방울·C 원기둥·D 블록), 주인공은 알 껍질 |
| 환경 | KayKit CC0 로우폴리(`client/public/assets/kaykit/CREDITS.md`), 공유 텍스처 채도 보정 |
| 조명 | 부드러운 반구광 + 약한 방향광, 톤 매핑 없음 |

## 5. Abraxas에 맞춘 튜닝

레퍼런스와 일부러 다르게 가는 부분.

| 레퍼런스 | Abraxas | 이유 |
| --- | --- | --- |
| 하트·느낌표·물음표 감정 버블이 반응을 강하게 보여 줌 | 측정 문항 반응은 '공감 / 생각에 잠김' 두 가지만, 좋고 나쁨이 없는 중립 연출. 하트는 에피소드 끝에만 | 측정 오염 방지 정책 2·3 |
| 선택지 색·순서로 정답을 암시하는 경우가 있음 | 선택지는 모두 같은 모양·색, 순서는 데이터 그대로 | 정책 5 |
| 부드러운 파스텔 | 한 단계 더 선명한 색 | 사람 결정(선명하게) |
| 원근 있는 카메라 | 원근 없는 정사영 디오라마 | 사람 결정 |
| 동물 주민 | 성별 중립 SD 사람형, 실루엣 4종 | 기획: 공략 캐릭터 4명, 성별 중립 |
| 주민 이름 | 공략 A·B·C·D(임시), 퀘스트 NPC는 코드 이름(`s1j2`) | 사람 결정 |
| 수치·호감도 UI(우정도 등) | 플레이 중 수치·축 이름·호감도 표시 없음 | 정책 4 |
