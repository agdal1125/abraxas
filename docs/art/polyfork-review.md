# Polyfork 에셋 검토

2026-11-07 · 대상: [polyfork-catalog](https://github.com/lucas-martinic/polyfork-catalog), 모델 2,791개와 키트 26종

저장소는 목록만 담고 있고, 모델은 polyfork.dev에서 받는다. 중세 마을 키트 13종을 받아 우리 에셋과 같은 조명·같은 높이로 비교했다. 받은 파일은 저장소에 넣지 않았다.

## 라이선스 (2026-11 기준 [공식 안내](https://polyfork.dev/licensing))

| 대상 | 조건 |
| --- | --- |
| GLB·FBX·USD·OBJ 메시 | CC BY 4.0 또는 Polyfork 라이선스 중 선택 |
| `.mjs` 소스, HD판, 렌더 이미지 | Polyfork 라이선스만 적용, 재배포 금지 |

이 저장소는 공개이므로 GLB를 커밋하면 파일을 재배포하는 셈이다. 메시를 쓰려면 CC BY 4.0을 택하고 모델별 출처를 설정 메뉴의 출처 표기에 넣는다. `.mjs`는 저장소에 넣지 않는다.

## 가져올 제작 원칙

1. 부재를 하나씩 만든다. 술통은 널판, 우물은 돌덩이, 지붕은 기와로 나눈다.
2. 부재마다 색을 조금씩 달리한다. 나무는 세 가지 나무색, 돌은 세 가지 돌색을 돌려 쓴다.
3. 완벽한 직선을 피한다. 울타리 기둥은 기울이고, 가로대는 한 번 꺾고, 지붕 선은 처지게 한다.
4. 구조가 말이 되게 만든다. 반목조 뼈대, 트러스, 뚫린 작업장처럼 실제 짜임을 보여 준다.
5. 재료가 다른 곳은 대비를 준다. 쇠 테와 쇠 틀은 어둡게, 램프 유리는 밝게 한다.
6. 나무 밑동은 넓게 벌려 땅에 심긴 것처럼 보이게 한다.

## 가져오지 않을 것

- 건물과 주역의 직접 교체. 치수·충돌·색이 달라 맞추는 비용이 크고, 마을의 고유한 인상을 잃는다.
- 사람 캐릭터. 3,700~4,300삼각형으로 우리 SD 비율과 맞지 않는다.
- 파스텔에서 벗어나는 올리브·겨자색 팔레트.
