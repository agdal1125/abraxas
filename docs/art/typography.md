# T014 글꼴 선정

2026-11-02. agy Argon4 사용량 한도로 Codex가 대신 선정했다.

## 비교

동일한 마을 배경과 15px 대사창에 한글과 영어를 함께 놓고 844×390 헤드리스 Edge 캡처를 비교했다. 배경은 기존 탐험 캡처를 사용한 비교용 재현 화면이며, 게임 실행 캡처는 아니다. 용량은 각 패키지의 일반 굵기 woff2 한글·기본 라틴 파일 합계이고 Pretendard는 통합 파일이다. 모든 후보의 동봉 라이선스는 SIL OFL 1.1로 상업적 사용과 재배포가 가능하다. 작은 글씨와 분위기 평가는 이 캡처를 기준으로 한 주관적 판단이다.

## 결정과 배포

본문과 제목 모두 Pretendard를 사용한다. 작은 대사의 선명도와 한글·영어의 일관성을 우선했고 기존 아트 가이드의 본문 방향과도 맞는다. 별도 제목 글꼴을 추가하는 대신 크기와 굵기로 위계를 만든다. 400과 700 굵기만 자체 호스팅하며 `font-display: swap`으로 대체 글꼴을 먼저 표시한다. 선택한 통합 파일에는 한글과 라틴이 함께 들어 있어 언어별 분할 요청이 없다. 글꼴과 원본 라이선스는 `client/public/fonts/pretendard/`에 둔다.

| 파일 | 크기 |
| --- | ---: |
| Pretendard-Regular.woff2 | 765,892바이트 |
| Pretendard-Bold.woff2 | 791,156바이트 |
| 두 글꼴 합계 | 1,557,048바이트 |

로컬 배포 빌드의 첫 제목 화면에서 Edge가 두 글꼴을 모두 요청했다. 응답 본문은 합계 1,557,048바이트, Resource Timing의 전송 크기는 합계 1,557,648바이트였다. 빌드 전체는 변경 전 4,104,537바이트에서 변경 후 5,667,457바이트로 1,562,920바이트 증가했다. 이는 첫 화면 전체 네트워크 전송량이 아닌 빌드 디렉터리 합계이며 10 MiB 검사에 통과했다. 네트워크 압축·캐시와 기기 환경에 따른 차이는 별도로 측정하지 않았다.
