# 아트 스타일 가이드 (초안)

레퍼런스: 기획 단계 첨부 이미지(쿼터뷰 농장 마을, 파스텔 톤, 둥근 SD 캐릭터). `docs/art/reference/`에 무드 이미지를 모은다.

## 한 줄 기준

동글동글하고 두툼한 로우폴리 느낌의 SD 캐릭터가 사는 파스텔 시골 마을을 쿼터뷰로 내려다본다.

## 화면·시점

- 가로 중심으로 16:9를 구성 기준으로 삼고 긴 가로 화면에도 대응한다. 모바일 세로에서는 회전 안내를 표시한다.
- 쿼터뷰(3/4 탑다운)를 유지하고 인물과 이동 공간이 잘 보이도록 대사창 위의 월드 영역에 구도를 잡는다.

## 캐릭터

- SD 2~2.5등신, 큰 머리, 단순한 눈·입. 외곽선은 얇고 부드럽게, 또는 없음.
- 공략 캐릭터 4명: 성별이 드러나는 고정 요소(체형·화장·특정 의상 코드)를 피하고 실루엣·색·소품으로 구분한다.

| 캐릭터 | 역할 | 대표 색 | 소품 아이디어 |
| --- | --- | --- | --- |
| 루미 | 축제 준비위원 | 산호 주황 | 깃발, 리본 |
| 모카 | 빵집 주인 | 따뜻한 갈색·크림 | 앞치마, 빵 바구니 |
| 에코 | 도서관 사서 | 라벤더 | 둥근 안경, 책 |
| 오르 | 대장장이 | 짙은 청록 | 작업 장갑, 망치 |

(색·소품은 가안. 성별 중립 원칙 안에서 조정)

- 주인공: 얼굴 세부를 그리지 않는 단순한 형태(예: 둥근 실루엣 + 점 눈). 알 껍질 모티프를 소품으로 쓸 수 있다.

## 글꼴

- 본문 UI: Pretendard (SIL OFL). 
- 제목·유형명: 둥근 계열 한글 디스플레이 폰트 1종 (라이선스 확인 후 확정).
- 웹폰트는 사용하는 글자만 서브셋으로 만들어 용량을 줄인다.

## 공통 프롬프트 머리말 (이미지 생성용)

```
cute chibi 3D-rendered isometric game art, quarter view, soft pastel palette,
chunky rounded low-poly shapes, soft baked shadows, cozy countryside village,
clean simple faces, no text, no logos
```

캐릭터 추가: `gender-neutral character design, 2.5 head-to-body ratio, transparent background, full body, front/three-quarter/side turnaround`

금지어로 넣을 것: 실존 게임·애니·브랜드 이름, 사진풍, 과한 디테일, 글자.

## 결과 카드

- 16유형 일러스트는 같은 틀(배경 원형 프레임 + 캐릭터 + 유형명 + 수식어)로 맞춘다.
- 공유 카드는 9:16(스토리용)과 1.91:1(링크 미리보기용) 두 가지.
