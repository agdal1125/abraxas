# ADR-0005 렌더링을 Phaser 4에서 Three.js로

- 상태: 확정 (2026-10-31, 사람 결정)
- 대체: ADR-0001의 '게임 클라이언트' 행 중 Phaser 4. TypeScript·Vite·inkjs·성향 계산 코어·서버 구성은 그대로.

## 결정

클라이언트 렌더링을 Three.js 3D 실시간으로 바꾼다. 원근 없는 정사영 쿼터뷰 고정 카메라로 디오라마처럼 보이는 마을을 걸어 다닌다. 대사·선택지·결과 UI는 HTML 오버레이로 그린다.

## 이유

- 1차 프로토타입(2D 대사창 구조)이 기획 의도(쿼터뷰 마을 탐색, 로우폴리 SD)와 어긋났다는 사람 피드백.
- 비교: 2D 아이소메트릭은 가장 쉽지만 입체감이 약하고, 2.5D 프리렌더는 렌더 파이프라인 비용이 크다. 3D 실시간은 CC0 로우폴리 키트(KayKit)를 그대로 쓸 수 있어 이번 규모에서 2D와 난이도 차이가 작다.
- 모바일 웹: WebGL은 Phaser와 같은 기반. 로우폴리·정사영·그림자 최소·픽셀 비율 2 제한으로 성능을 지킨다. 초기 로딩 10MB 한도 유지(에셋 약 2.3MB).

## 다시 검토할 조건

- 저사양 안드로이드·카카오톡 인앱에서 30fps를 못 지킬 때.
