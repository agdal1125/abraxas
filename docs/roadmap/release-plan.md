# 출시 계획

2026-11-08 사람 승인. 근거는 [벤치마크 리서치](../research/2026-11-benchmark.md), 역할과 게이트는 [작업 역할](../../.agents/rules/delegation.md)에 있다.

목표는 링크 하나로 바로 플레이하는, 출시 가능한 모바일 웹 게임이다.

## 순서

| 순서 | 묶음 | 내용 | 주 담당 | 끝 조건 |
| --- | --- | --- | --- | --- |
| M0 | 작업 기반 | 리서치 문서, agent 6, 스킬 7, 기존 스킬 개정, 문서의 Phaser 표기 정정 | 메인 | 각 agent를 작은 시험 과제로 실행 |
| M1 | 기준선 | 현재 빌드로 비평 5인 전체 플레이, 실제 폰 전 구간 측정, 실제 플레이타임, 계측 도입 | 비평가, 코더 | 우선순위 있는 문제 목록과 숫자 |
| M2 | 결과와 공유 | 16유형 이름과 일러스트, 결과 카드 시각 표현, 경계 축 표현, 작은 실험 카드, 세로 공유 이미지, OG, 네이티브·카카오 공유, 초대권 서버, 친구 비교 | UX, 그래픽, 코더, 심리학자 | 끝 화면만 보고도 공유하고 싶다는 사람 판정 |
| M3 | 30분의 재미 | 페이싱 감사와 삭제, 인물별 한 장면, 소리와 악기 모티프, 챕터 빛, 탐색 보상, 렌더 최적화 | 기획자, 그래픽, 코더 | 실제 사람 5명 완주, 이탈 지점 개선 |
| M4 | 심리 검증과 다듬기 | 심리 파일럿, 전문가 자문, 첫 60초, 접근성, 한/영 윤문, 다른 플레이어 통계 | 심리학자, UX | 주장 문구가 데이터와 맞음 |
| M5 | 출시 | 등급분류, 개인정보·약관, 운영 App Check와 규칙, 오류 수집, 광고 승인, 소프트 런칭, 음악 출처 정리 | 코더, 사람 | 소규모 공개 후 지표 확인 |

M1에 바로 넘기는 항목은 [M0 시험 보고](../reviews/m0-trial/README.md)에 있다.

M2를 M3 앞에 둔다. 끝이 있어야 사람 테스트에서 "다시 하고 공유하겠는가"를 물을 수 있다. M1에서 첫 3분 이탈이나 실기기 성능이 치명적으로 나오면 그것을 먼저 고친다.

마일스톤마다 실제 사람 5명 테스트를 따로 한다. 비평가 subagent는 막힘과 어색함을 찾는 데 쓰고 재미 판정은 대신하지 못한다.

## 사람이 결정할 것

추천을 시작값으로 두고 각 항목은 해당 단계 시작 전에 다시 묻는다.

| 시점 | 질문 | 추천 |
| --- | --- | --- |
| M1 | 분석 도구 | Firebase Analytics 또는 자체 서버 이벤트. 선택 내용은 수집하지 않고 구간 진입과 이탈만 |
| M2 | 16유형 이름과 세계관 | 도리마을 주민 별명식. 후보를 표로 제시 |
| M2 | 초대권 지급 시점 | 정책은 '공유 동작이 끝날 때' 지급이다. 네이티브 공유는 전송을 증명하지 못한다. 카카오 웹훅, 받은 사람의 접속 확인과 함께 비교한다 |
| M2 | 공유 보상 자체 | 다크 패턴 소지와 플랫폼 정책을 확인한다. 무료 재플레이 1회와 공유 보상의 조합도 비교한다 |
| M3 | 플레이타임 | 측정값을 보고 판단한다. 32분과 38문항 변경은 정책 변경이라 승인이 필요하다 |
| M5 | 등급분류와 법적 검토 | 광고를 넣으면 비영리 면제가 어려울 수 있어 GRAC 또는 전문가에게 확인한다 |
| M5 | 광고 | H5 Games Ads 승인 전까지 무광고 출시 여부 |

## 설치 목록

외부 도구는 사용자 환경을 바꾸므로 항목별로 확인받는다.

| 역할 | 도구 | 상태 |
| --- | --- | --- |
| 그래픽 | `@gltf-transform/cli`, `blender-mcp`(선택) | 미설치 |
| 코더 | `three-best-practices`, `threejs-skills` 일부, 플러그인 `playwright`, `sentry`, `firebase` | 미설치 |
| 기획자 | `analytics-office`(선택) | 미설치 |
| 심리학자 | `Marketing Psychology Kit` | 미설치 |
| 비평가 | `Kobiton`(선택, 유료) | 미설치 |
| UX | 플러그인 `frontend-design`, `design-skills`(선택) | 미설치 |

제외한 도구는 Meshy 같은 AI 3D 생성과 `blender-skills` 묶음이다. 스타일 일관성을 깨고 지금의 Blender 생성 스크립트와 겹친다. `figma`는 설치돼 있으나 `/mcp` 인증 전까지 쓸 수 없고 필수도 아니다.
