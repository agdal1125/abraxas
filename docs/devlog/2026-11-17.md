- 현재 빌드(`npm run build`)의 `dist/index.html`과 청크를 보고 CSP를 맞췄다. 인라인 스크립트는 없고, 인라인 `<style>` 하나, three 청크, 글꼴, Draco 디코더, 오프닝 mp4가 모두 같은 출처다. Firebase 인증은 `getAuth`라서 `apis.google.com`과 `*.firebaseapp.com` 프레임이 필요하다.

- 서버 `go vet`, `go test` 통과. 클라이언트 타입 검사와 vitest 233개 통과.
