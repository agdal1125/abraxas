## 세션 1 (windows) · 미니게임 묶음을 새 main 위에 다시 쌓음
- 유형: 구현
- 시스템: 심부름, 클라이언트, 서버

2026-11-08 기준으로 쓴 PR 네 개(#103~#106)를 신호판 UI와 T021~T027이 들어간 main 위에 브랜치 네 개로 다시 만들었다. 옛 브랜치는 병합하지 않았다.

### 한 일
- `feat/minigames-v2`: 주민마다 다른 심부름 미니게임(루미 리본 기억, 모카 오븐 타이밍, 에코 서가 정렬, 오르 톱니). 서버는 그대로이고 판을 이기면 기존 배치 명령을 보낸다. 성공과 실패는 점수와 호감도에 들어가지 않는다.
- `feat/shorter-errands-v2`: 집기와 돌아가기 단계를 없앴다(서버 상태 기계 포함). T021의 전하기 목표 문구는 그대로 두고 집기·돌아가기 키만 지웠다. 옛 PR의 E2E 탭 재시도는 가져오지 않았고 #134의 리비전 확인을 그대로 둔다. 검증된 한 판의 명령을 앞질러 보내면 서버가 거절하고 상태를 바꾸지 않는다는 시험(`errand_skip_test.go`)을 더했다.
- `feat/minigame-art-v2`: 판 그림(SVG), 가로 화면 배치, 동작 줄이기에서 움직임 끄기.
- `feat/minigame-sound-v2`: Web Audio 합성 효과음과 설정의 '소리' 켜기·끄기(`hud.sound`). 측정 선택지는 소리가 없다.

### 확인
- 브랜치마다 client `tsc --noEmit`, `vitest run --no-file-parallelism`(238개), `npm run ink`, `check-visible-names`, `check-dialogue`. 내용을 바꾼 브랜치는 `check:scoring`. 서버를 바꾼 브랜치는 `go vet`, `go test`.
- 마지막 브랜치에서 `npm run build`, `check:size`(dist 6.57 MB).

### 하지 않은 것 / 다음
- E2E(`scripts/e2e-play.mjs`)와 실제 화면, 실제 폰 소리는 확인하지 않았다. 메인 세션이 E2E를 돌린다.
- [ ] 옛 PR 병합 순서 정리와 닫기는 사람이 결정한다.

## 세션 2 (windows) · 미니게임 심리 검토의 필수 수정
- 유형: 수정
- 시스템: 심부름, 클라이언트, 문구

심리 검토(`docs/psych/2026-11-17-minigames.md`)가 루미 리본 게임과 에코 서가 게임이 바로 앞 C축 답(lumi_04, echo_04)을 무시하고 '익숙한 쪽'을 하게 만든다고 지적했다. 문제를 만든 브랜치에서 고치고 위 브랜치로 합쳤다.

### 한 일
- `feat/minigames-v2`: 루미 howto를 두 답 공통으로("장식이 빛나는 순서…") 바꾸고, lumi_04=b이면 새 키 `game.marksField`(솔방울, 노란 잎, 초록 잎, 붉은 잎)와 색을 쓴다. 순서 길이, 시드, 음 높이, 판 수, 완료 문구는 그대로다. 에코 howto와 cleared를 "정한 방식대로"와 "정한 자리에 섰어요!"로 바꿨다(ko·en 같은 뜻).
- `feat/minigame-art-v2`: 합치면서 lumi_04=b이면 BOW 대신 솔방울 1개와 잎 3개를 그린다. 판 변형은 이 브랜치의 `round.variant`("field")를 쓴다.
- 위 두 수정을 `shorter-errands-v2`, `minigame-art-v2`, `minigame-sound-v2`로 차례로 합쳤다. 심리 검토 기록을 맨 위 브랜치에 넣었다.
- `residentBoard`는 마지막 인자로 답 목록을 받는다. 호출하는 `game.ts` 한 줄이 바뀐다.

### 하지 않은 것 / 다음
- 에코 책등 색을 목표 위치별로 묶는 권고는 필수가 아니라서 넣지 않았다. 모카 진열 장면, or_02 b 낚시꾼 줄, 오답음 바꾸기도 검토 기록의 "나중에"에 남겼다.
- 루미를 답에 따라 나눌지 중립 장식으로 바꿀지는 사람이 정한다(분기안으로 만들었다).
- 렌더와 화면은 보지 못했다. DOM 시험 환경이 없어 판 문구 전환의 단위 시험은 만들지 않았다. ko·en 캡처(lumi_04 a·b, echo_04 a·b)는 재검에 필요하다.
