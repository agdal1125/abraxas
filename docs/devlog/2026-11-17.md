## 세션 1 (windows) · 미니게임 묶음을 새 main 위에 다시 쌓음
- 유형: 구현
- 시스템: 심부름, 클라이언트, 서버

2026-11-08 기준으로 쓴 PR 네 개(#103~#106)를 신호판 UI와 T021~T027이 들어간 main 위에 브랜치 네 개로 다시 만들었다. 옛 브랜치는 병합하지 않았다.

### 한 일
- `feat/minigames-v2`: 주민마다 다른 심부름 미니게임(루미 리본 기억, 모카 오븐 타이밍, 에코 서가 정렬, 오르 톱니). 서버는 그대로이고 판을 이기면 기존 배치 명령을 보낸다. 성공과 실패는 점수와 호감도에 들어가지 않는다.
- `feat/shorter-errands-v2`: 집기와 돌아가기 단계를 없앴다(서버 상태 기계 포함). T021의 전하기 목표 문구는 그대로 두고 집기·돌아가기 키만 지웠다. 옛 PR의 E2E 탭 재시도는 가져오지 않았고 #134의 리비전 확인을 그대로 둔다. 검증된 한 판의 명령을 앞질러 보내면 서버가 거절하고 상태를 바꾸지 않는다는 시험(`errand_skip_test.go`)을 더했다.
- `feat/minigame-art-v2`: 판 그림(SVG), 가로 화면 배치, 동작 줄이기에서 움직임 끄기.
- `feat/minigame-sound-v2`: Web Audio 합성 효과음과 설정의 '소리' 켜기·끄기(`hud.sound`). 측정 선택지는 소리가 없다.

### 확인
- 브랜치마다 client `tsc --noEmit`, `vitest run --no-file-parallelism`(238개), `npm run ink`, `check-visible-names`, `check-dialogue`. 내용을 바꾼 브랜치는 `check:scoring`. 서버를 바꾼 브랜치는 `go vet`, `go test`.
- 마지막 브랜치에서 `npm run build`, `check:size`(dist 6.57 MB).
