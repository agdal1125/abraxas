- 사용자가 부모의 상위 환경 사용을 로컬 검증과 저장소 관리 범위로 승인했다. 구현자는 제한된 샌드박스를 유지했다. 전역 설정·ACL·운영 프로젝트·비밀값·배포는 변경하지 않았다.

### 배운 것
- Windows ACL 허용과 자동 승인 검토는 별개다. 원래 거부 원인을 단정하지 않고, 기본 관리 worktree에서 일반 편집이 가능한 환경을 사용했다.
- Firestore 준비 확인에는 루트 상태 응답을 사용한다. 비어 있는 문서 경로의 404와 deny-all 규칙의 403은 준비 실패를 뜻하지 않는다.
- 브라우저 자동화도 실제 UI 입력 가능 상태를 기다려야 한다. 결과 도달뿐 아니라 HTTP·콘솔·프로세스·정리 오류로 종료 상태를 판정한다.
