# 공유 메모리

Claude Code, Antigravity(App·CLI·IDE), 사람이 함께 쓰는 프로젝트 기억이다. git으로 버전 관리되므로 누가 언제 무엇을 바꿨는지 남는다.

| 파일 | 담는 것 | 누가 쓰나 |
| --- | --- | --- |
| `decisions.md` | 사람이 확정한 결정과 이유 | 에이전트가 초안, 사람이 확인 |
| `status.md` | 지금 단계, 다음 할 일, 열린 질문 | 작업한 에이전트 |
| `lessons.md` | 겪은 함정과 해결법 | 작업한 에이전트 |

## 세 겹 구조

1. **규칙** (`AGENTS.md`, `.agents/rules/`): 바뀌지 않는 원칙. 매번 또는 필요할 때 자동으로 읽힌다.
2. **공유 메모리** (`docs/memory/`): 결정·상태·교훈. 작업 시작과 끝에 읽고 쓴다.
3. **기록** (`docs/devlog/`, 노션 개발 일지): 날짜별 작업 기록. 사람이 돌아볼 때 쓴다.

도구별 자체 메모리(Antigravity의 brain 폴더, Claude의 메모리)는 편의용 캐시다. 내용이 다르면 이 폴더가 기준이다.
