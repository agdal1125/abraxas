# Abraxas 몽환(Dream-like) 환경 팔레트 v2 확정표

- **작성일:** 2026-11-01
- **담당:** agy (`gemini-4-argon-medium`)
- **반영 피드백:** 몽환 파스텔 시험판(`dream-compare.png` 오른쪽)의 파스텔 무드는 유지하되, **'조금 더 진하게'** — 특히 잔디·나무 수관·흙길·지붕의 채도를 시험판 대비 **+15~25%** 높여 흐릿함을 줄이고, 명도는 비슷하게 유지한다. 캐릭터 대표색(`#FF7A59` 등)은 수정하지 않는다.
