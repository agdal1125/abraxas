# 아트 에셋 출처 및 라이선스 (Credits)

## 1. 캐릭터 초상 (`char/*.svg`)

- **원작**: [Notionists](https://heyzoish.gumroad.com/l/notionists) by **Zoish**, [DiceBear API (9.x)](https://www.dicebear.com/styles/notionists/) 제공
- **라이선스**: [CC0 1.0 Universal (Public Domain Dedication)](https://creativecommons.org/publicdomain/zero/1.0/)
- **원본 URL**:
  - `char/lumi.svg`: `https://api.dicebear.com/9.x/notionists/svg?seed=lumi&backgroundColor=ffc9a8`
  - `char/moka.svg`: `https://api.dicebear.com/9.x/notionists/svg?seed=moka&backgroundColor=f1dcc0`
  - `char/echo.svg`: `https://api.dicebear.com/9.x/notionists/svg?seed=echo&backgroundColor=ddd0f2`
  - `char/or.svg`: `https://api.dicebear.com/9.x/notionists/svg?seed=or&backgroundColor=b8e0da`
- **커스터마이즈 내용**:
  - 각 파일 내부의 `<metadata>`(라이선스·작성자 정보)는 원본 그대로 보존.
  - 마스크를 원형(`rx="872" ry="872"`)으로 다듬고, 바깥에 캐릭터별 대표색(`docs/art/style-guide.md` 기준: 루미 산호 주황 `#F28B5B`, 모카 따뜻한 갈색 `#A67B5B`, 에코 라벤더 `#9B7EDE`, 오르 짙은 청록 `#3D8B85`)의 둥근 테두리 원(`<circle>`)을 추가. 성별을 드러내는 고정 요소는 추가하지 않음.

## 2. 배경 일러스트 (`bg/*.svg`)

- **파일**:
  - `bg/village.svg`: 시골 마을 어귀와 광장
  - `bg/festival.svg`: 같은 광장의 밤 축제 (등불, 깃발)
  - `bg/gate.svg`: 신비로운 기억의 문 (알 껍질 모티프, 은은한 빛)
- **출처**: 이 저장소(Abraxas 프로젝트)에서 직접 제작
- **라이선스**: [CC0 1.0 Universal (Public Domain Dedication)](https://creativecommons.org/publicdomain/zero/1.0/)으로 둠.
